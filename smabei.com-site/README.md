# Sambei Website

## Structure

- `index.html`: main homepage.
- `css/style.css`: all visual and responsive styles.
- `images/products/`: the three original product images.
- `logo/`: Sambei logo and favicon.
- `robots.txt`: search engine crawl rules.
- `sitemap.xml`: sitemap for `https://smabei.com/`.

## Product images

- `smart-fitness-mirror.jpg`: screen casting smart fitness mirror.
- `solid-wood-mobile-mirror.jpg`: movable solid wood full-length mirror.
- `metal-rolling-mirror.png`: rolling metal full-length mirror.

To replace a product image without changing code, use the same filename and image format.

## Deployment

Upload the contents of this folder to the web root for `smabei.com`. Keep the folder structure unchanged.
